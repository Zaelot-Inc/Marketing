## Data integrity issues found while building this

1. **The 1stDibs Salesforce AI deal lost $120,000 with no debrief.** Created 5/8, lost 8/14. No loss reason recorded anywhere in HubSpot or the repo.
2. **Three owners across three contacts.** 538395758 on Slalom, 358403244 on MSG, 87748049 and 81015182 across 1stDibs. Event-sourced records are scattered across reps with no shared event tag, which is why event attribution has to be reconstructed from creation dates rather than read directly.
3. **No event source tagging exists on any record.** There is no campaign, source, or custom property marking a contact as World Tour sourced. Every funnel number in this report is inferred from a date window, which is the root cause of the attribution disputes throughout this whole report series.
4. **Joseph Tesoriero has no title and one note.** Effectively an empty record.
5. **The FDE credit value is unrecorded**, so real money cannot be prioritized.

## What this says about event strategy

This event's value was correctly identified as partner-network depth, and the CRM bears that out: two of three new contacts are Slalom. That is not a failure, it is what a partner event produces.

The more interesting finding is that the recap overstates the pipeline claim while understating what actually happened. 1stDibs and MSG were not surfaced here, they were already open opportunities, one of them since February 2024. But a $120,000 deal was created ten days after the event and it did lose, which is a real if unsuccessful outcome that the recap does not mention.

The unresolved item that matters most is not a deal at all. It is the FDE credits, which remain unquantified. An event whose clearest financial output is an unclaimed credit program is an event we have not finished attending.
